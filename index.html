Fundamento Puente Conceptual

Del Sitemap Visual al File Tree Real

Un sitio web no es una colección de archivos desordenados en el escritorio: es un sistema jerárquico.

1. Sitemap (Diagrama Lógico)

Define cómo el usuario y los motores de búsqueda experimentan la navegación.

🏠 Inicio (Home)
☕ Carta / Menú
🌱 Nosotros
📍 Contacto

Representación orientada a la experiencia del usuario (UX).

2. File Tree (Estructura Física)

Cómo se implementa en el disco duro y en el servidor web de producción:

📁 proyecto-web/
│── 📄 index.html <-- Puerta de entrada (Home)
│── 📁 pages/ <-- Subpáginas del sitio
│ ├── 📄 carta.html
│ ├── 📄 nosotros.html
│ └── 📄 contacto.html
└── 📁 assets/ <-- Recursos estáticos
    ├── 📁 img/
    └── 📁 css/

Regla de oro: Nunca dejes todas las páginas sueltas en la raíz del proyecto.

Técnica Crítica Sintaxis Web

Dominando las Rutas Relativas

La ruta depende exclusivamente de dónde estoy parado en este momento dentro del árbol.

Operadores de Navegación

./ : "En este mismo directorio actual" (o implícito sin punto).
../ : "Sube un nivel hacia la carpeta padre".

Página Actual Destino Atributo href Correcto
index.html (Raíz) Carta href="pages/carta.html"
carta.html (en /pages/) Inicio href="../index.html"
carta.html (en /pages/) Contacto href="contacto.html" o ./

⚠️ Los 2 Pecados Capitales del Principiante

1. Usar rutas absolutas de tu máquina:
<!-- NUNCA HAGAS ESTO: Se romperá en la web --> <a href="C:/Users/Juan/MiProyecto/pages/carta.html">
2. Olvidar subir con ../ desde una subpágina:
<!-- En pages/carta.html buscando volver a la raíz: --> <a href="index.html"> <!-- ❌ ERROR 404: Busca pages/index.html --> <a href="../index.html"> <!-- ✓ CORRECTO: Sube a la raíz -->
Accesibilidad & UI Buenas Prácticas

Navegación Global y Estado Activo

El usuario nunca debe sentirse perdido: el menú debe indicar en qué página se encuentra.

En la Raíz: index.html

El enlace a Inicio es la página actual, y los demás apuntan hacia adentro de la carpeta pages/.

<header> <nav aria-label="Navegación principal"> <ul> <li><a href="index.html" aria-current="page">Inicio</a></li> <li><a href="pages/carta.html">Carta</a></li> <li><a href="pages/nosotros.html">Nosotros</a></li> <li><a href="pages/contacto.html">Contacto</a></li> </ul> </nav> </header>

En una Subpágina: pages/carta.html

Debemos salir con ../ para ir al Inicio, navegar como hermanas a las demás, y marcar Carta como activa.

<header> <nav aria-label="Navegación principal"> <ul> <li><a href="../index.html">Inicio</a></li> <li><a href="carta.html" aria-current="page">Carta</a></li> <li><a href="nosotros.html">Nosotros</a></li> <li><a href="contacto.html">Contacto</a></li> </ul> </nav> </header>
Caso de Estudio Real Laboratorio Práctico

Negocio: "Origen Café & Tostaduría"

Una cafetería de especialidad artesanal que necesita un sitio web informativo estructurado.

☕

1. Home (index.html)

Propuesta de valor, variedades destacadas de grano y llamado a visitar el local.

📋

2. Carta de Cafés (pages/carta.html)

Listas ordenadas y descriptivas de métodos de extracción (V60, Chemex) y repostería.

🌱

3. Sobre Nosotros (pages/nosotros.html)

Historia de los caficultores de Villa Rica y Cusco, filosofía de comercio justo.

📍

4. Contacto y Horarios (pages/contacto.html)

Dirección del local, enlaces de WhatsApp, correo institucional y horarios de atención.

Arquitectura de Archivos Estructura Oficial

File Tree de "Origen Café"

Esta es la estructura exacta que deben crear en su explorador de archivos de VS Code:

📁 origen-cafe/
│── 📄 index.html <-- Título: "Origen Café | Tostaduría de Especialidad"
│
│── 📁 pages/
│ ├── 📄 carta.html <-- Título: "Nuestra Carta | Origen Café"
│ ├── 📄 nosotros.html <-- Título: "Historia y Fincas | Origen Café"
│ └── 📄 contacto.html <-- Título: "Visítanos y Contacto | Origen Café"
│
└── 📁 assets/
    ├── 📁 img/ <-- (Listo para la Sesión 8 de Imágenes)
    └── 📁 css/ <-- (Listo para el Bloque 2 de CSS)

📌 Convenciones Profesionales

  • ✓ Todo en minúsculas: carta.html (no Carta.HTML).
  • ✓ Sin espacios ni tildes: Usa guiones medios (ej: sobre-nosotros.html).
  • ✓ Carpetas semánticas: Separar código de presentación de activos estáticos (/assets).

🎯 Preparación para el Parcial

Tener esta estructura limpia hoy les ahorrará el 80% de los problemas de enlaces rotos cuando agreguemos imágenes en la próxima sesión.

Taller en Vivo 60 Minutos

Laboratorio: Red de Navegación 100% Funcional

Sigue las fases en orden. No uses estilos CSS; enfócate en la jerarquía semántica y las rutas.

Fases de Ejecución

1

Crear el File Tree: Crea la carpeta raíz origen-cafe en VS Code con sus subcarpetas pages/ y assets/img/.

2

Boilerplates Semánticos: En los 4 archivos HTML genera el esqueleto base (! + Tab), define lang="es" y un <title> descriptivo para cada página.

3

Header y Nav Global: Maqueta el menú en index.html. Luego cópialo a las subpáginas aplicando cuidadosamente las rutas relativas (../).

4

Contenido Mínimo Viable: En cada página agrega <main> con al menos un <h1> y un <section> representativo con texto.

5

Prueba Bidireccional: Navega desde index.html hacia carta.html, desde carta.html hacia contacto.html y vuelve al inicio sin tocar el botón atrás del navegador.

Checklist de Evaluación Formativa

☑️ 4 archivos HTML creados en sus rutas debidas.
☑️ Menú <nav> presente y funcional en las 4 páginas.
☑️ Cero errores 404 en la consola o pantalla.
☑️ Uso correcto de aria-current="page".
☑️ Títulos específicos en cada pestaña del navegador.
💡 Tip de Debugging: Abre con Live Server desde la carpeta raíz origen-cafe, no abriendo páginas sueltas.
Dinámica de Calidad 10 Minutos

Auditoría Cruzada: "Rompe el Sitio"

Los mejores desarrolladores prueban su código sometiéndolo a ojos de terceros.

Instrucciones de la Dinámica

  1. Intercambia asiento o pantalla con el compañero de al lado.
  2. Inicia en index.html mediante Live Server.
  3. Haz clic en cada enlace del menú en las 4 páginas (total 16 clics cruzados).
  4. Si encuentras una página en blanco o un Cannot GET /..., tu compañero debe corregir la ruta relativa en vivo.
